# 配筋表确定性规范化规则

## 方向与规范写法

| 方向 | 含义 | 规范写法 |
| --- | --- | --- |
| X | 水平筋 | `1D22间距200` |
| Y | 竖向筋 | `1D22间距200` |
| Z | 拉筋 | `1C12间距200*400` |

- 输入 `1 22@200`、`1D22@200`、`1D22间距200` 均规范为 `1D22间距200`。
- 输入 `1A8间距400*400` 强制规范为 `1C8间距400*400`。
- 输出不保留 `#`。
- `S7157A`、`S7157a` 统一为独立墙号 `S7157A`，不能合并到 `S7157`。

## 精确面积公式

钢筋截面积始终用 Python `math.pi`：

`bar_area = math.pi * (diameter / 2) ** 2`

X/Y 每延米实际配筋面积：

`actual_area = layers * bar_area * (1000 / spacing)`

Z 每平方米实际配筋面积：

`actual_area = layers * bar_area * (1000 / spacing_primary) * (1000 / spacing_secondary)`

示例：

- `1D40间距200`：`math.pi * 20**2 * 5 = 6283.185307179587`
- `1D36间距200`：`math.pi * 18**2 * 5 = 5089.380098815464`
- `1C14间距400*400`：`math.pi * 7**2 * 2.5 * 2.5 = 962.1127501618741`

包络、大小比较和候选选择使用上述未舍入值。计算书正文或表格显示时才按项目规则舍入，例如分别显示为 `6283.2`、`5089.4`、`962.1`。

## 括号、重复行与人工确认

- `1D36间距200（1 40@200）` 使用括号内值 `1D40间距200` 作为实际值。
- 若括号中出现多个可识别候选，只在括号内候选中按精确实际面积取最大值。
- 同一墙号存在两行或更多行时，保留所有行，输出重复墙号列表并标记 `requires_manual_confirmation=true`。
- 任一单元格无法解析时，报告工作表、墙号、单元格和原始错误，不得猜测缺失值。
