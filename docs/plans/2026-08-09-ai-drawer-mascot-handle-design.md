# AI 抽屉机器人缩放手柄设计

## 目标

AI 助手窗口打开后，右侧页面入口机器人不再消失，而是切换成一个趴在窗口左上角的蓝白 Q 版机器人。打开态只露出脑袋和抓住窗口边缘的双手，并成为窗口唯一的收起和缩放入口：单击收起窗口，按住拖动调整窗口大小。

本功能仅面向公司内网桌面 Edge/Chrome，不增加手机端、触屏专用逻辑、外部图片、CDN 或第三方动画依赖。

## 已批准方案

采用单一组合控件方案：机器人同时替换现有左上角缩放手柄和右上角收起箭头。

- 单击或键盘 Enter/空格：收起 AI 窗口。
- 从机器人按下并移动超过 5 CSS px：进入窗口缩放，不执行收起。
- 方向键：保持现有键盘缩放能力；Shift+方向键继续使用较大步长。
- 向左上拖动放大，向右下拖动缩小，与现有抽屉锚定在右下角的几何逻辑一致。

不保留第二个收起按钮，避免重复入口和头部视觉竞争。

## 视觉设计

**视觉主张：** 同一只蓝白 Q 版机器人从页面边缘“爬到”AI 窗口左上角，露出圆形屏幕脸和两只抓住边框的手，让缩放手柄从机械符号变成有生命感的窗口把手。

- 复用关闭态机器人的蓝、白、浅青、腮红和深蓝描边。
- 打开态使用独立的半身 SVG 视图，只绘制天线、头部、眼睛和双手，不显示身体。
- 机器人位于抽屉内部左上角并覆盖头部边界线，避免被抽屉现有 `overflow: hidden` 裁切。
- 标题区域左侧增加固定留白，保证机器人不遮挡 “AI Assistant / AI 助手”。
- 控件保持透明底色，不增加卡片、圆形按钮底座或新的装饰色。
- 焦点轮廓贴合机器人可点击区域，并保持与现有蓝色焦点样式一致。

## 交互状态

控件采用四个明确状态：

1. `rest`：只显示趴窗机器人。
2. `hover` / `focus`：机器人轻微抬头，向右显示气泡“点我隐藏窗口”。
3. `pressed`：按下后立即显示气泡“按住我拖动，调整窗口大小”，双手轻微压住边框。
4. `dragging`：累计位移超过 5px 后调整窗口尺寸，保持按住气泡；松开后回到悬停或静止状态，禁止这一轮 click 收起窗口。

指针移动未超过阈值时不改变窗口尺寸，松开后仍按普通 click 收起。`pointerup`、`pointercancel` 和组件卸载都会移除临时监听，避免残留拖动状态。

## 组件结构

新增 `AiDrawerMascotHandle.tsx`：

- 输出一个语义化 `button`，可访问名称为“隐藏或调整 AI 助手窗口”。
- 内联半身机器人 SVG，不请求任何外部资源。
- 管理悬停、焦点和按住的视觉状态。
- 接收 `onHide`、`onResizePointerDown` 和 `onResizeKeyDown` 回调，不接触聊天数据或抽屉尺寸持久化。

`AiChatDrawer.tsx` 继续负责：

- 现有窗口尺寸状态和上下限裁剪。
- 5px 拖动阈值、指针监听和拖动后 click 抑制。
- 抽屉收起动画、localStorage 状态和关闭后的焦点恢复。

现有关闭态 `AiMascotTrigger` 保持不变。抽屉打开时渲染 `AiDrawerMascotHandle`，收起完成后仍恢复焦点到页面右侧入口机器人。

## 可访问性与桌面兼容性

- Enter/空格通过按钮原生 click 收起窗口。
- 方向键继续调整宽高，Shift 提供较大步长。
- 焦点时展示与悬停相同的“点我隐藏窗口”提示。
- 气泡仅作视觉说明，按钮可访问名称完整表达操作，不重复进入朗读顺序。
- 使用 Pointer Events、SVG、CSS Modules 和原生事件监听，兼容当前公司内网 Chromium Edge/Chrome。
- 不新增手机端媒体查询或触屏手势分支。
- `prefers-reduced-motion: reduce` 下禁用机器人过渡和按压动画，但保留状态和文本提示。

## 测试与验收

- 组件测试：悬停/焦点显示收起提示；按住显示缩放提示；点击调用收起；方向键转发缩放；指针取消恢复状态。
- 抽屉集成测试：打开态存在机器人手柄；旧缩放符号和右上角箭头不存在；单击机器人收起；超过阈值的拖动改变尺寸且不收起；阈值内移动仍按点击收起。
- 布局测试：机器人位于抽屉左上角、头部留白充分、气泡向右展开、没有新增手机端规则。
- 回归测试：关闭态入口机器人、Escape 收起、焦点恢复、聊天与附件逻辑不回归。
- 完整验证：定向 Vitest、全量 `npm test -- --run`、`npm run build`。
- 桌面实测：在 1366×768 下检查机器人只露头和双手、气泡不越界、单击和拖动互不误触、抽屉缩放结果正常持久化。
- 独立审查：由新的设计审查子 agent 检查角色一致性、趴窗姿态、气泡可读性、拖动可发现性和头部遮挡风险。
