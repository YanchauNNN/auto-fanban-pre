# 计算书任务 AI 配筋规范化设计

## 目标

计算书任务上传压缩包后，后端先检查其中的配筋 Excel 是否符合标准输入格式。标准格式直接进入现有确定性流程；非标准格式在用户明确确认后创建任务，并由任务 Worker 调用大模型和配筋规范化 Skill，将工作簿内容转换为后端可验证的结构化字段。大模型不生成新 Excel，配筋面积仍全部由后端精确公式计算。

任务不因重复配筋行、`-1/-2` 图片组、墙体数量差异或部分字段无法确定而暂停。能够确定的内容继续生成；无法确定的内容在计算书中留空，任务完成后在“查看任务”界面集中提示用户人工补充。

## 标准格式判定

预检阶段只执行快速、确定性的格式检查，不调用大模型。

- 墙体表接受标准模板的四列表头及其允许写法，包括模板中的 `1 22@200`、规范写法 `1D22间距200` 和标准拉筋网格写法。
- 楼板表使用 `楼板配筋` Sheet，包含标高、顶层/中层/底层水平竖向和纵向拉筋表头；Middle 单元格可以为空。
- 标准结构中出现括号局部配置、无法识别的额外列、非标准表头或无法由标准规则直接读取的布局时，判为非标准格式。
- 未勾选楼板应力时，不因未使用的楼板 Sheet 触发 AI；勾选后同时检查楼板数据。

预检发现非标准格式时返回 `requires_ai_normalization=true`、触发原因和预检令牌，而不是把它当作上传失败。前端显示固定提示：

> 您上传的墙体配筋表非标准格式，程序将启动人工智能。

用户确认后，创建请求携带 `confirm_ai_normalization=true`，任务立即进入队列。

## 大模型输入与 Skill 调用

Worker 的第一个阶段为 `ai_reinforcement_normalization`。

1. 从任务压缩包提取唯一配筋工作簿。
2. 后端将工作簿转换为无损的单元格快照，保留 Sheet、行列地址、值、公式和合并单元格信息。这样不要求模型直接读取 XLSX 二进制。
3. 使用现有 AI 网关配置和 `reinforcement_table_normalizer` Skill，将 Skill 规则、工作簿快照和严格 JSON Schema 一并发送给模型。
4. 模型只负责字段映射和规范表达，不负责计算配筋面积，也不返回文件。

结构化输出分为墙体和楼板：

- 墙体字段：来源 Sheet、来源行、来源单元格、墙号、X/Y/Z 规范规格、状态和问题原因。
- 楼板字段：来源 Sheet、来源行、来源单元格、标高、顶层/中层/底层水平竖向、纵向拉筋、状态和问题原因。
- 每个业务源行必须恰好输出一次，状态为 `normalized` 或 `needs_review`。
- 无法确定的字段必须返回 `null`，不得猜测或用相邻行补全。

## 后端校验与计算

模型结果不是最终事实。后端收到结构化字段后必须重新验证：

- 来源 Sheet、行号和单元格必须存在，且不能用同一来源行伪造多条输出。
- 源业务行数必须等于 `normalized + needs_review`，墙体数量不得静默减少。
- 墙号、标高和钢筋规格继续使用现有确定性解析器校验。
- X/Y 和墙体 Z、楼板线性钢筋分别使用现有精确公式计算，模型返回的面积字段即使存在也忽略。
- 括号内值、大小包络、`A → C`、独立后缀墙号、Middle 5/7 组等规则仍由后端执行或复核。
- 模型服务不可用、JSON 不符合 Schema、整表漏行或来源证据失真时，任务失败并记录明确诊断；不能在缺少整体可信度时继续生成。

## 有歧义内容的生成规则

通过整体校验后，局部 `needs_review` 不阻断任务：

- 重复配筋行：对应墙体的配筋规格和计算说明留空，保留图片与墙号。
- `-1/-2` 图片组无法唯一对应：相应配筋内容留空。
- 仅图片存在的墙体：保留可确定的图片位置，配筋字段留空。
- 仅表格存在的墙体：不凭空生成图片段落，在提醒清单中列出。
- 楼板某方向无法确定：该方向的规格、面积和说明留空，其余已确定方向继续生成。

每个留空项写入任务结果的 `calculation_book_warnings`，包含类型、墙号或标高、方向、来源 Sheet/行/单元格、原始值、原因和受影响的输出字段。

## 前端交互

### 创建任务

- 标准表：保持现有流程，不出现 AI 提示。
- 非标准表：显示醒目的确认卡片和固定提示，说明 AI 只做格式转换、结果仍由后端校验和计算。
- 用户确认后按钮文案为“确认并开始任务”，任务直接进入队列。

### 查看任务

任务仍使用现有完成状态和下载入口，不新增暂停状态。详情页增加：

- “AI 已规范化非标准配筋表”状态标识；
- “需人工补充 N 项”汇总卡；
- 按墙体、楼板标高和问题类型分组的可展开清单；
- 每项显示来源位置、原因、留空字段和建议补充内容；
- 无警告时不显示空卡片，避免干扰标准任务。

视觉层级复用当前出图任务详情模式，并单独进行页面美感、可读性和使用性审查。

## 审计与可观测性

任务元数据记录：

- 是否检测为标准格式；
- 用户是否确认启动 AI；
- Skill ID、模型配置名、调用次数和耗时；
- 源行、规范化行、待补充行数量；
- 后端 Schema/行守恒校验结果；
- 不保存密钥，不在普通日志中记录完整工作簿内容。

## 验证范围

1. 标准墙体表不触发 AI。
2. 标准墙体加标准楼板表不触发 AI。
3. 非标准墙体表提示用户并在确认后由 Worker 调用模型。
4. 非标准楼板表在勾选楼板时触发 AI，并输出 5 组或 7 组字段。
5. 模型结构化输出由后端复核并使用精确公式计算。
6. 重复行、`-1/-2`、墙体数量差异和局部空值不阻断任务，产物留空且任务详情展示提醒。
7. 模型整体输出漏行或非法时任务失败，不能误报成功。
8. 使用真实业务压缩包验证预检、任务入队、AI 调用、生成、提醒和下载全流程。
