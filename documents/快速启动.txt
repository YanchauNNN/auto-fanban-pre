开发环境快速启动（PowerShell）

测试本轮最新功能请使用第 3 组：http://127.0.0.1:5175/。
端口固定：main 8010 / 5173；旧统一空间 18182 / 5186；当前开发空间 18183 / 5175（API / 前端）。
8000 保留给部署环境，本文件中的开发命令不使用该端口。
同一组的 API、Worker、前端分别在三个新的 PowerShell 窗口运行；不要混用不同组，也不要为同一组重复启动 Worker。
更新代码后请在原窗口按 Ctrl+C 停止对应服务，再按同组命令启动；前端端口占用时直接报错，不自动换端口。
各组使用自己的配置、账号和 storage；main 中已有任务不会自动出现在当前开发空间，本次不迁移任务数据。

1. 主空间 main

API（PowerShell 窗口 1）：
Set-Location 'E:\project\auto-fanban-pre'
$env:FANBAN_STORAGE_DIR = Join-Path $PWD.Path 'storage'
$env:FANBAN_SPEC_PATH = Join-Path $PWD.Path 'documents\参数规范.yaml'
$env:FANBAN_RUNTIME_SPEC_PATH = Join-Path $PWD.Path 'documents\参数规范_运行期.yaml'
$env:FANBAN_MECHANISM_SPEC_PATH = Join-Path $PWD.Path 'documents\参数规范-3.yaml'
$env:FANBAN_AI_SPEC_PATH = Join-Path $PWD.Path 'documents\AI\参数规范_AI.yaml'
uv run --project backend python -X utf8 -m uvicorn API.app.main:app --host 127.0.0.1 --port 8010

Worker（PowerShell 窗口 2）：
Set-Location 'E:\project\auto-fanban-pre'
$env:FANBAN_STORAGE_DIR = Join-Path $PWD.Path 'storage'
$env:FANBAN_SPEC_PATH = Join-Path $PWD.Path 'documents\参数规范.yaml'
$env:FANBAN_RUNTIME_SPEC_PATH = Join-Path $PWD.Path 'documents\参数规范_运行期.yaml'
$env:FANBAN_MECHANISM_SPEC_PATH = Join-Path $PWD.Path 'documents\参数规范-3.yaml'
$env:FANBAN_AI_SPEC_PATH = Join-Path $PWD.Path 'documents\AI\参数规范_AI.yaml'
uv run --project backend python -X utf8 -m API.app.worker

前端（PowerShell 窗口 3）：
Set-Location 'E:\project\auto-fanban-pre\frontend'
$env:VITE_API_BASE_URL='/'
$env:VITE_API_PROXY_TARGET='http://127.0.0.1:8010'
npm.cmd run dev -- --host 127.0.0.1 --port 5173 --strictPort

访问地址：http://127.0.0.1:5173/

API 连通检查：
Invoke-RestMethod 'http://127.0.0.1:8010/api/system/ping'

系统与 Worker 健康检查（ready、worker_alive 应为 True）：
Invoke-RestMethod 'http://127.0.0.1:8010/api/system/health'
