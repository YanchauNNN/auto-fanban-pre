# 厂房索引图替换前端接入指导

## 背景
- 后端已经把厂房索引图替换接入 `audit_replace` 翻版主链。
- 前端暂时不需要配置模板文件，也不需要执行 CAD 识别。
- 前端只需要在目标项目需要区分岛号时，向后端补充岛号参数。

## 后端已支持的目标模板
- `target_project_no=1818`：使用 `1818项目厂房索引图.dwg`
- `target_project_no=1907`：使用 `1907项目厂房索引图.dwg`
- `target_project_no=2026`：使用 `2026项目厂房索引图.dwg`
- `target_project_no=1916`：
  - `target_island_no=3`：使用 `1916项目3号岛厂房索引图.dwg`
  - `target_island_no=4`：使用 `1916项目4号岛厂房索引图.dwg`
- `target_project_no=2016`：
  - `target_island_no=1`：使用 `2016项目1号岛厂房索引图.dwg`
  - `target_island_no=2`：使用 `2016项目2号岛厂房索引图.dwg`

## 前端字段要求
- 保持现有字段：
  - `source_project_no`
  - `target_project_no`
  - `dwg_files[]`
  - `run_deliverable`
- 新增字段：
  - `source_island_no`
  - `target_island_no`
- `source_island_no` 只在来源项目为 `2016` 或 `1916` 时显示并提交。
- `target_island_no` 只在目标项目为 `2016` 或 `1916` 时显示并提交。
- 后端现在会校验：来源/目标项目需要区分机组/岛号时，对应字段缺失会返回 `422`。

## 交互建议
- 当用户选择 `source_project_no=2016`：
  - 展示“来源机组号”下拉框
  - 候选：`1号机组`、`2号机组`
  - 提交值：`1` 或 `2`
- 当用户选择 `source_project_no=1916`：
  - 展示“来源岛号”下拉框
  - 候选：`3号岛`、`4号岛`
  - 提交值：`3` 或 `4`
- 当用户选择 `target_project_no=1916`：
  - 展示“目标岛号”下拉框
  - 候选：`3号岛`、`4号岛`
  - 提交值：`3` 或 `4`
- 当用户选择 `target_project_no=2016`：
  - 展示“目标岛号”下拉框
  - 候选：`1号岛`、`2号岛`
  - 提交值：`1` 或 `2`
- 当目标项目为 `1818/1907/2026`：
  - 隐藏目标岛号字段
  - 不提交 `target_island_no`，或提交空值
- 当来源项目为 `1818/1907/2026`：
  - 隐藏来源机组/岛号字段
  - 不提交 `source_island_no`，或提交空值

## 后端参数格式
```json
{
  "source_project_no": "2016",
  "source_island_no": "1",
  "target_project_no": "1916",
  "target_island_no": "3"
}
```

后端也兼容以下目标参数名，但前端推荐统一使用 `target_island_no`：
- `factory_index_map_variant`
- `target_island_no`
- `island_no`

后端也兼容以下来源参数名，但前端推荐统一使用 `source_island_no`：
- `source_factory_index_map_variant`
- `source_island_no`
- `source_unit_no`

## 来源块识别规则
- `2016` 来源项目：
  - `source_island_no=1`：只替换块内含 `QF` 的厂房索引图。
  - `source_island_no=2`：只替换块内不含 `QF` 的厂房索引图。
- `1916` 来源项目：
  - `source_island_no=3`：只替换块内含 `KP` 的厂房索引图。
  - `source_island_no=4`：只替换块内不含 `KP` 的厂房索引图。
- 前端不需要执行这些规则，只负责提交来源机组/岛号；规则由后端 YAML 驱动。

## 校验错误
- 来源项目为 `2016/1916` 但未提交来源机组/岛号：
  - `param_errors.source_island_no = ["required_for_source_project"]`
- 目标项目为 `2016/1916` 但未提交目标机组/岛号：
  - `param_errors.target_island_no = ["required_for_target_project"]`
- 机组/岛号值不在项目允许范围内：
  - `unsupported_source_island_no`
  - `unsupported_target_island_no`

## 配置保存要求
- 如果当前翻版配置会保存到草稿或预设，`source_island_no`、`target_island_no` 也必须一起保存。
- 当用户切换目标项目导致岛号字段隐藏时，可以保留草稿值，但提交时仅在 `target_project_no=1916/2016` 时发送。
- 当用户切换来源项目导致来源字段隐藏时，可以保留草稿值，但提交时仅在 `source_project_no=1916/2016` 时发送。

## 任务详情展示
后端会在任务详情里继续返回：
```json
{
  "factory_index_map": {
    "applied": true,
    "action_count": 1,
    "report_json": "...",
    "message": ""
  }
}
```

展示建议：
- 普通成功场景不需要单独弹窗。
- 调试面板或任务详情可以展示 `applied/action_count/message`。
- 如果 `message` 不为空，前端可展示为普通提示，不要阻断下载。

## 注意事项
- 前端不要自己判断模板文件名。
- 前端不要读取或解析 DWG。
- 前端不要做块替换逻辑。
- 厂房索引图替换是翻版后端主链的一部分；如果用户选择“同步出图和翻版”，后端会先生成 `replaced.dwg`，再用它作为出图输入。
