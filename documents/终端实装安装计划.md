# 终端实装：首次安装与更新

默认安装目录：`D:\FanBanServer`。

部署包解压后，必须保证以下目录直接位于 `D:\FanBanServer` 下，不能多出一层 `fanban-terminal-deploy` 目录：

```text
D:\FanBanServer\frontend-dist
D:\FanBanServer\backend-runtime
D:\FanBanServer\documents
D:\FanBanServer\documents_bin
D:\FanBanServer\install
D:\FanBanServer\scripts
```

所有 PowerShell 命令均以管理员身份执行。执行 Office/Excel 任务的业务账号必须保持登录。

## 一、首次安装

1. 将完整部署包解压到 `D:\FanBanServer`。
2. 在管理员 PowerShell 中执行以下命令；将 `DOMAIN\用户名` 改为实际运行后端及 Office 的登录账号。

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

$DeployRoot = 'D:\FanBanServer'
$BackendUser = 'DOMAIN\用户名'

powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\check_iis_proxy_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_iis_proxy_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_runtime_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\prepare_terminal.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\deep_check_terminal.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\configure_iis_site.ps1" -SiteName FanBanTerminal -Port 8888
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\register_backend_task.ps1" -UserName $BackendUser
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\test_ai_model_connectivity.ps1" -Profile terminal_cnpe_intranet_qwen_fast
```

3. `check_health.ps1` 通过后，访问：

```text
http://部署机IP:8888/
```

现场使用 80 端口时，将首次安装命令中的 `-Port 8888` 改为 `-Port 80`，访问地址不再填写端口。

## 二、常规更新

适用于前端、后端、YAML、模板、`documents`、`documents_bin` 和脚本更新。

1. 解压新的完整部署包到临时目录，例如 `D:\FanBanUpdate\fanban-terminal-deploy`。
2. 执行以下命令。命令会保留历史任务和日志，不覆盖 `storage`、`logs`。

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

$DeployRoot = 'D:\FanBanServer'
$PackageRoot = 'D:\FanBanUpdate\fanban-terminal-deploy'

Stop-ScheduledTask -TaskName FanBanBackend -ErrorAction SilentlyContinue
$deadline = (Get-Date).AddSeconds(30)
while ((Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue) -and (Get-Date) -lt $deadline) {
    Start-Sleep -Seconds 2
}
if (Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue) {
    throw '后端未在 30 秒内停止，请确认 FanBanBackend 已停止后再覆盖。'
}

robocopy $PackageRoot $DeployRoot /E /COPY:DAT /DCOPY:DAT /R:2 /W:2 /XD storage logs
if ($LASTEXITCODE -gt 7) { throw "部署文件复制失败，robocopy exit code: $LASTEXITCODE" }

Start-ScheduledTask -TaskName FanBanBackend
Restart-WebAppPool -Name FanBanTerminalAppPool
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1"
```

3. 浏览器按 `Ctrl+F5` 刷新页面，确认新前端资源已加载。

## 三、仅更新前端

适用于只替换 `frontend-dist` 的更新。

```powershell
$DeployRoot = 'D:\FanBanServer'
$FrontendSource = 'D:\FanBanUpdate\fanban-terminal-deploy\frontend-dist'

robocopy $FrontendSource "$DeployRoot\frontend-dist" /MIR /R:2 /W:2
if ($LASTEXITCODE -gt 7) { throw "前端文件复制失败，robocopy exit code: $LASTEXITCODE" }

Restart-WebAppPool -Name FanBanTerminalAppPool
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1"
```

随后在浏览器按 `Ctrl+F5`。

## 四、仅在以下情况追加执行

### Python 运行时或依赖包有更新

```powershell
Stop-ScheduledTask -TaskName FanBanBackend -ErrorAction SilentlyContinue
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\install\install_runtime_prereqs.ps1
Start-ScheduledTask -TaskName FanBanBackend
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\scripts\check_health.ps1
```

## 六、AI 模型连通性检查

首次安装完成后，或 AI 网关、AI 配置更新后，执行以下命令验证终端内网模型服务：

```powershell
$DeployRoot = 'D:\FanBanServer'
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\test_ai_model_connectivity.ps1" -Profile terminal_cnpe_intranet_qwen_fast
```

通过时控制台显示 `AI connectivity status: passed`。详细诊断 JSON 默认写入 `D:\FanBanServer\storage\ai\diagnostics\`；其中不应只根据流式结果的 `done_received=false` 判定失败，应以总状态和 `errors` 为准。

### IIS 端口、站点或反向代理配置有更新

```powershell
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\install\configure_iis_site.ps1 -SiteName FanBanTerminal -Port 8888
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\scripts\check_health.ps1
```

### 后端运行账号或计划任务定义有更新

```powershell
$BackendUser = 'DOMAIN\用户名'
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\install\register_backend_task.ps1 -UserName $BackendUser
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\scripts\check_health.ps1
```

## 五、启停命令

```powershell
# 停止后端
Stop-ScheduledTask -TaskName FanBanBackend

# 启动后端
Start-ScheduledTask -TaskName FanBanBackend

# 检查部署状态
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\scripts\check_health.ps1
```
