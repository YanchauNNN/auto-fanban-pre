# 终端实装：首次安装与更新

默认安装目录：`D:\FanBanServer`。

部署包解压后，必须保证以下目录直接位于 `D:\FanBanServer` 下，不能多出一层 `fanban-terminal-deploy` 目录：

```text
D:\FanBanServer\frontend-dist
D:\FanBanServer\backend-runtime
D:\FanBanServer\bin\7-Zip
D:\FanBanServer\documents
D:\FanBanServer\documents_bin
D:\FanBanServer\install
D:\FanBanServer\scripts
```

`D:\FanBanServer\bin\7-Zip` 必须只包含同版 `7z.exe`、`7z.dll`、
`License.txt`、`PROVENANCE.txt`。该运行时是随部署包携带的私有便携副本：不执行安装、
不修改系统 PATH，也不回退调用系统 `tar.exe`、`7z.exe` 或其他同名命令。

其中 `documents` 至少要随包携带同版业务参数文件：

```text
D:\FanBanServer\documents\参数规范.yaml
D:\FanBanServer\documents\参数规范_运行期.yaml
D:\FanBanServer\documents\参数规范-3.yaml
D:\FanBanServer\documents\AI\参数规范_AI.yaml
D:\FanBanServer\documents\AI\ai_model_gateway.yaml
```

所有 PowerShell 命令均以管理员身份执行。执行 Office/Excel 任务的业务账号必须保持登录。

## 一、首次安装

1. 将完整部署包解压到 `D:\FanBanServer`。
2. 在管理员 PowerShell 中执行以下命令；将 `DOMAIN\用户名` 改为实际运行后端及 Office 的登录账号。

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

$DeployRoot = 'D:\FanBanServer'
$BackendUser = 'DOMAIN\用户名'

powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\check_iis_proxy_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_iis_proxy_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_runtime_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\prepare_terminal.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\deep_check_terminal.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\configure_iis_site.ps1" -SiteName FanBanTerminal -Port 8888
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\register_backend_task.ps1" -UserName $BackendUser
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\test_ai_model_connectivity.ps1" -Profile terminal_cnpe_intranet_qwen_fast
```

3. `check_health.ps1` 通过后，访问：

```text
http://部署机IP:8888/
```

现场使用 80 端口时，将首次安装命令中的 `-Port 8888` 改为 `-Port 80`，访问地址不再填写端口。

## 二、常规更新

适用于前端、后端、YAML、模板、`documents`、`documents_bin`、AI Skill 和脚本更新。

1. 解压新的完整部署包到临时目录，例如 `D:\FanBanUpdate\fanban-terminal-deploy`。
2. 执行以下命令。命令会保留历史任务和日志，不覆盖 `storage`、`logs`。

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

$DeployRoot = 'D:\FanBanServer'
$PackageRoot = 'D:\FanBanUpdate\fanban-terminal-deploy'

Stop-ScheduledTask -TaskName FanBanBackend -ErrorAction SilentlyContinue
$deadline = (Get-Date).AddSeconds(30)
while ((Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue) -and (Get-Date) -lt $deadline) {
    Start-Sleep -Seconds 2
}
if (Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue) {
    throw '后端未在 30 秒内停止，请确认 FanBanBackend 已停止后再覆盖。'
}

robocopy $PackageRoot $DeployRoot /E /COPY:DAT /DCOPY:DAT /R:2 /W:2 /XD storage logs
if ($LASTEXITCODE -gt 7) { throw "部署文件复制失败，robocopy exit code: $LASTEXITCODE" }

# 常规复制会保留 storage；只同步部署包中受管的 AI Skill 子目录。
$ManagedAiSkillRoots = @(
    'ansys-mapdl-18-2',
    'building-structure-standards',
    'reinforcement-table-normalizer'
)
foreach ($SkillName in $ManagedAiSkillRoots) {
    $SkillSource = Join-Path $PackageRoot ("storage\ai\skills\{0}" -f $SkillName)
    if (Test-Path -LiteralPath $SkillSource -PathType Container) {
        $SkillDestination = Join-Path $DeployRoot ("storage\ai\skills\{0}" -f $SkillName)
        robocopy $SkillSource $SkillDestination /MIR /COPY:DAT /DCOPY:DAT /R:2 /W:2
        if ($LASTEXITCODE -gt 7) { throw "AI Skill 复制失败 ($SkillName)，robocopy exit code: $LASTEXITCODE" }
    }
}

powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\prepare_terminal.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\deep_check_terminal.ps1"
Start-ScheduledTask -TaskName FanBanBackend
Restart-WebAppPool -Name FanBanTerminalAppPool
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1"
```

3. 浏览器按 `Ctrl+F5` 刷新页面，确认新前端资源已加载。

## 三、仅更新前端

适用于只替换 `frontend-dist` 的更新。

```powershell
$DeployRoot = 'D:\FanBanServer'
$FrontendSource = 'D:\FanBanUpdate\fanban-terminal-deploy\frontend-dist'

robocopy $FrontendSource "$DeployRoot\frontend-dist" /MIR /R:2 /W:2
if ($LASTEXITCODE -gt 7) { throw "前端文件复制失败，robocopy exit code: $LASTEXITCODE" }

Restart-WebAppPool -Name FanBanTerminalAppPool
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1"
```

随后在浏览器按 `Ctrl+F5`。

```powershell
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\scripts\check_health.ps1
```

## 五、AI 模型连通性检查

首次安装完成后，或 AI 网关、AI 配置更新后，执行：

```powershell
$DeployRoot = 'D:\FanBanServer'
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\test_ai_model_connectivity.ps1" -Profile terminal_cnpe_intranet_qwen_fast
```

通过时控制台显示 `AI connectivity status: passed`。详细诊断 JSON 默认写入 `D:\FanBanServer\storage\ai\diagnostics\`；以总状态和 `errors` 为准，不单独根据 `done_received=false` 判定失败。

## 六、私有压缩运行时探针与失败处理

`prepare_terminal.ps1`、`deep_check_terminal.ps1` 和 `start_backend.ps1` 都会调用包内
Python `archive_runtime_probe`。探针先按 `documents\参数规范-3.yaml` 验证四个运行时文件、
7-Zip 版本和 `7z/zip/Rar/Rar5` handler，再分别执行 ZIP、7z、RAR5 的 list+x 微烟测，
并精确核对解出的合成 payload 文件名、大小和 SHA-256。

RAR5 样本只包含 40 字节合成测试文本；来源记录位于
`backend-runtime\backend\src\deploy\fixtures\PROVENANCE.md`，部署包不包含 WinRAR
可执行文件、库、安装器或许可材料。

任一校验失败时：

1. `probe_target_env.ps1` 写入 `archive_runtime` 顶层结果，并追加
   `section=archive_runtime, code=archive_runtime_probe` 的 blocking issue；
2. `prepare_terminal.ps1` 不生成新的 `runtime.env.ps1`；
3. `deep_check_terminal.ps1` 返回失败；
4. `start_backend.ps1` 在创建 API/worker 子进程前停止。

此时不要临时改 PATH 或复制系统 7-Zip 规避探针，应重新下发同版完整部署包并复验。

## 七、启停命令

```powershell
powershell -ExecutionPolicy Bypass -File D:\FanBanServer\scripts\check_health.ps1
```

## 八、构建机交付前检查

```powershell
rg -n "E:\\project|E:/project|auto-fanban-pre" build\fanban-terminal-deploy\scripts build\fanban-terminal-deploy\backend-runtime build\fanban-terminal-deploy\frontend-dist build\fanban-terminal-deploy\install
rg --files build\fanban-terminal-deploy\backend-runtime build\fanban-terminal-deploy\scripts build\fanban-terminal-deploy\install -g "*.lscache" -g "direct_url.json" -g "_auto_fanban.pth" -g "_editable_impl_auto_fanban.pth" -g "a1_coverage.pth" -g ".build_packages/**"
Get-ChildItem build\fanban-terminal-deploy\backend-runtime,build\fanban-terminal-deploy\scripts,build\fanban-terminal-deploy\install -Recurse -Force | Where-Object { $_.Name -eq "__pycache__" -or $_.Extension -eq ".pyc" }
```

交付标准：

- 构建成功，单元测试通过。
- 前端以 `frontend-dist`、后端以 `backend-runtime` 为准。
- YAML、`documents`、`documents_bin`、`Resources` 和受管 AI Skill 随包携带且同版。
- 不命中开发机绝对路径，不携带 `.lscache`、editable 安装记录或测试覆盖率残留。
- 真实业务样本冒烟通过后再交付。
