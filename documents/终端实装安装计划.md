# FanBan 终端实装操作手册

## 1. 首次安装命令

将完整部署包的内容直接解压到 `D:\FanBanServer`。解压后应直接看到 `frontend-dist`、`backend-runtime`、`install`、`scripts`，不能再多一层目录。

使用实际承担后端和 Office COM 任务的 Windows 登录账号，以管理员身份打开 PowerShell，复制执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

$DeployRoot = 'D:\FanBanServer'
$BackendUser = "$env:USERDOMAIN\$env:USERNAME"   # 如后端使用其他登录账号，请改成实际账号
$IisPort = 8888

powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\check_iis_proxy_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_iis_proxy_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_runtime_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\prepare_terminal.ps1" -OfficeProbeMode deep
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\configure_iis_site.ps1" -SiteName FanBanTerminal -Port $IisPort
powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\register_backend_task.ps1" -UserName $BackendUser -Port 8000

$deadline = (Get-Date).AddMinutes(5)
do {
    try {
        Invoke-RestMethod -Uri 'http://127.0.0.1:8000/api/system/ping' -TimeoutSec 5 | Out-Null
        $apiReady = $true
    } catch {
        $apiReady = $false
        Start-Sleep -Seconds 5
    }
} until ($apiReady -or (Get-Date) -ge $deadline)
if (-not $apiReady) {
    throw 'API 未在 5 分钟内启动，请查看 D:\FanBanServer\logs\backend-latest-stderr.log'
}

powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1" -Mode deep
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\test_ai_model_connectivity.ps1" -Profile terminal_cnpe_intranet_qwen_fast
```

安装完成后访问：

```text
http://部署机IP:8888/
```

如现场使用 80 端口，把 `$IisPort = 8888` 改为 `80`，访问地址不再填写端口。

### 2.3 账号、工作量和计算书完整业务验收

先把真实计算书测试压缩包复制到部署机，例如 `D:\FanBanProbe\calculation-book.rar`。命令会安全提示输入系统业务账号密码，密码只写入当前 PowerShell 进程的环境变量，不进入命令行或探针日志。

```powershell
$DeployRoot = 'D:\FanBanServer'
$CalculationArchive = 'D:\FanBanProbe\calculation-book.rar'
$ProbeCredential = Get-Credential -Message '请输入 FanBan 业务探针账号'

$env:FANBAN_PROBE_USERNAME = $ProbeCredential.UserName
$env:FANBAN_PROBE_PASSWORD = $ProbeCredential.GetNetworkCredential().Password
try {
    powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\run_deployment_probes.ps1" `
        -PackageRoot $DeployRoot `
        -ApiBaseUrl 'http://127.0.0.1:8000' `
        -RunCalculationSmoke `
        -CalculationArchive $CalculationArchive
} finally {
    Remove-Item Env:FANBAN_PROBE_USERNAME -ErrorAction SilentlyContinue
    Remove-Item Env:FANBAN_PROBE_PASSWORD -ErrorAction SilentlyContinue
}
```

只检查计算书环境、Skill、模板、解压能力和 API 契约，不创建真实计算书任务时，删除 `-RunCalculationSmoke` 和 `-CalculationArchive` 两行。

验收标准：

- `check_health.summary.json` 的 `overall_status` 为 `pass`。
- AI 连通性脚本显示 `AI connectivity status: passed`。
- `logs\deployment-probes\<时间>\summary.json` 的 `status` 为 `PASS`。
- 完整计算书烟测生成有效 DOCX，诊断日志最后一条事件为 `task_completed`。

## 3. 更新安装命令

将新完整部署包的内容直接覆盖到 `D:\FanBanServer`，不要再套一层
`fanban-terminal-deploy` 目录。覆盖时保留既有 `storage`、`logs` 和
`documents_bin\姓名角色表.csv`；完成覆盖后，以管理员身份执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

$DeployRoot = 'D:\FanBanServer'

if (-not (Test-Path -LiteralPath "$DeployRoot\package-manifest.json" -PathType Leaf)) {
    throw '覆盖后的部署目录不完整：缺少 package-manifest.json。'
}

Stop-ScheduledTask -TaskName FanBanBackend -ErrorAction SilentlyContinue
$deadline = (Get-Date).AddSeconds(30)
while (
    (Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue) -and
    (Get-Date) -lt $deadline
) {
    Start-Sleep -Seconds 2
}
if (Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue) {
    throw '后端未在 30 秒内停止，请先排查 FanBanBackend，再继续更新。'
}

powershell -ExecutionPolicy Bypass -File "$DeployRoot\install\install_runtime_prereqs.ps1"
powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\prepare_terminal.ps1" -OfficeProbeMode deep
Start-ScheduledTask -TaskName FanBanBackend
Restart-WebAppPool -Name FanBanTerminalAppPool

$deadline = (Get-Date).AddMinutes(5)
do {
    try {
        Invoke-RestMethod -Uri 'http://127.0.0.1:8000/api/system/ping' -TimeoutSec 5 | Out-Null
        $apiReady = $true
    } catch {
        $apiReady = $false
        Start-Sleep -Seconds 5
    }
} until ($apiReady -or (Get-Date) -ge $deadline)
if (-not $apiReady) {
    throw '更新后 API 未在 5 分钟内启动，请查看 backend-latest-stderr.log。'
}

powershell -ExecutionPolicy Bypass -File "$DeployRoot\scripts\check_health.ps1" -Mode deep
```

更新完成后，再执行第 2 节的 AI 连通性和完整业务验收，并在浏览器按 `Ctrl+F5` 刷新前端资源。

## 必须知道的事项

- 上述命令均在管理员 PowerShell 中执行。
- Office COM 依赖交互式桌面会话；后端任务账号必须保持 Windows 已登录状态。
- 正常启动只使用 `FanBanBackend` 计划任务；`start_backend.ps1` 会同时托管 API 和 Worker，不要再单独启动 Worker。
- 更新时使用完整部署包；没有可靠基线时不要只复制 delta 包。
- 探针不通过即表示对应环境或业务模块未达到上线条件，不得仅凭网页能打开判定成功。
